Welcome to **NeuroNexus**, a beautifully styled,  Google Form-like landing page built using only **HTML** and **CSS** – no JavaScript involved!

## 🌟 Features

- Clean and responsive layout
- Fields:
  - Full Name
  - Contact Number (validated: 10 digits)
  - Address
  - Company Name
  - Email Address
  - Department (Dropdown)
  - Gender (Radio Buttons)
- Form validation using pure HTML
- Stylish submit button with hover effect
- Custom thank-you message using CSS-only transition
- Modern UI with subtle shadows and contrasting background
